- Node 24 / TypeScript / Fastify 模块化单体；Vue3/Three.js 蓝本复制，原目录不修改。

- 运行：`npm install`；`docker compose up -d`；复制 `.env.example`；`npm run migrate`；`npm run dev` / `npm run dev:web`。
- 本机 Node 24.12.0；Docker 不可用，容器启动尚未验证。
