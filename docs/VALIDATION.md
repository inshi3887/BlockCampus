# 阶段一验证记录

日期：2026-10-30。环境：Windows / Node24.12 / npm11.6；校园项目独立Git仓库，原 guangzhou 无修改。

| 项目 | 结果 | 范围 |
| --- | --- | --- |
| TypeScript / Vite | 通过 | 严格类型、游戏与独立运营端构建 |
| 单元/领域/API | 通过 | `npm test`，PGlite/真实PostgreSQL SQL引擎、内存Redis测试替身 |
| S3协议 | 通过 | `npm run test:storage`，实际AWS SDK HTTP请求及字节内容；本机协议桩 |

API覆盖：

- 未实名403、Cookie会话撤销、Origin伪造403、运营名预留、敏感词拒绝。
- 存档只准角色/设置/位置，经济注入400，版本冲突409。
- 同键并发购买只扣一次；不同键并发购买不会透支；五级条件由服务端检查；不存在兑换端点。
- 重复拍照事件返回同一回执，10秒冷却；普通20/广告5上限，超限无奖励。
- 课程提前结束不结算；完整服务端进度只结算一次；两分钟离线/后台中断；五分钟未确认不累计。
- 帖子待审、审核重复不重发、广告活动快照绑定、论坛公开且朋友圈对他人隐藏。
- 升级10/9/8/7/2/2、两类各10000次分层掉落期望24/87.95、商品纯外观及解锁字段。

浏览器：使用隔离QA后端（内存PostgreSQL/cache，虚构测试用户），1280×720，验证登录、账号不导入游客角色、角色创建、校门渲染、0余额HUD、五级商品锁定、校园生活导航、角色跨会话恢复、50席课堂开始/提前结算按钮禁用/离座无积分、论坛提交后显示审核中。QA账户不接触用户真实账号/证件；正式实名认证仍需按README启动完整依赖。

性能：蓝本副本仅加真实帧间隔显示，未修改原目录。在相同内嵌浏览器中，原版广州塔显示约1FPS/728 calls，校园校门约1FPS/500–660 calls。场景不同、浏览器运行环境异常，不能宣称同场景性能等价或60FPS已通过。内测阶段不承诺 60FPS，待目标机复测；硬件复测方法见README。

学校为广东工业大学示意校园，缺乏实测平立面资料，非实测建筑复刻。真实课程/国家认证/好友关系/多人/GPS重合/抢点均未伪装成已交付功能。
